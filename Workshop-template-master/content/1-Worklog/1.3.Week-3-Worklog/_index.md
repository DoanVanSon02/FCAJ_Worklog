## Week 3 Objectives:

- Understand the functions of Amazon EC2 and its basic configuration components.
- Practice creating an EC2 instance on the prepared network infrastructure.
- Learn how to connect via SSH and perform basic operations on a Linux server.
- Deploy a Web Server and verify website access.

## Week 3 Results:

- Understood the roles of AMI, Instance Type, and Key Pair when creating an EC2 instance.
- Created an EC2 instance on the prepared network infrastructure.
- Connected via SSH and performed basic Linux operations.
