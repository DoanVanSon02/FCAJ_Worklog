## Week 5 Objectives:

- Understand the roles and differences between Amazon EBS and Amazon S3.
- Practice managing EBS Volumes and creating Snapshots.
- Learn about S3 Bucket, Object, and Versioning.
- Practice copying data from EC2 to S3 using an IAM Role.

## Week 5 Results:

- Distinguished the storage functions of Amazon EBS and Amazon S3.
- Created and used an EBS Volume on EC2.
- Created a Snapshot and checked the data after recovery.
- Created an S3 Bucket and enabled Versioning to store multiple versions of data.
